# Timeline, library and export follow-up

Date: 2026-10-03. Base: WarpBro main c0627ac.

## Changes

- Timeline outline/time-canvas divider: a six-point drag target, horizontal-resize cursor, saved authored width, double-click reset. Narrow panels clamp drawing without overwriting the saved width. Registered after the row/canvas hit regions so the gesture reaches the divider. A reserved splitter gesture suppresses the shared canvas trim intents, whose geometric grab zones extend outside the canvas; dragging the divider must never edit a layer span.
- One adaptive thumbnail-grid calculation drives workspace Materials, preset Material Library, Gallery and Bookmarks. Scene cards retain their aspect ratio and use bounded labels.
- Material Library is a separate dockable/floating panel, reachable through Window or Materials → Library. Its fifty preset previews use the existing asynchronous thumbnail cache. Opening/drawing the library creates no nodes. Clicking a preset explicitly creates/selects a workspace Material node and opens the universal Attribute Editor; it does not assign objects.
- GPU HEVC uses the shared ffmpeg-rs Vulkan Video backend by default. Software is an explicit alternative, never an automatic fallback. Initialization errors identify the resolution/backend and suggest the CPU choice.
- RGB/planar YUV/NV12 conversion buffers and scaler contexts belong to one export writer and are reused. RGB → YUV420P performs BT.709 full-to-limited color conversion; YUV420P → NV12 only packs chroma. Direct RGB → NV12 is not supported by the pinned scaler.
- Cancel closes input gracefully, drains complete queued frames, flushes delayed encoder packets, writes the MP4 index/edit timing and atomically publishes the partial movie. Incomplete CUDA work is cancelled. Zero completed frames creates no movie. Error/abort paths retain atomic-output cleanup.
- Cancellation/finalization runs on the coordinator/writer threads. UI cancellation only sets an atomic flag; progress uses try_lock. Existing bounded render commands and one-frame writer backpressure remain.

## Reproduced video defect

The user supplied C:\\Temp\\renders\\frame.mp4 (51 frames, 2048×2048, HEVC, 24 fps).
Genuine FFmpeg software decoding reproduces the moving rectangular artifacts without reporting malformed bitstream errors. The EXR sequence alongside it depicts a different scene and cannot serve as an oracle for this movie.

A controlled 51-frame 256×256 moving spiral was generated by
export::tests::hevc_motion_fixture_encodes_every_source_frame. Every source RGB byte is retained when WARP_BRO_VIDEO_FIXTURE is set. The previous CPU configuration used the pinned ffmpeg-rs hevc_kvz medium preset, QP 18, with inter prediction. Independent FFmpeg decoding shows displaced rectangular strips even though the source is clean. The same source through hevc_vulkan at QP 18 has no such strips.

Before mitigation, RGB PSNR was 32.54 dB for the CPU inter path and 35.22 dB for Vulkan. CPU per-frame RMSE rose to 15.11 at the tail; Vulkan remained between 4.32 and 5.43. These figures include the shared RGB/YUV420 chroma conversion and are not a lossless-codec promise.

The application disables Kvazaar inter presets and exposes the bounded no-preset all-intra route as CPU · Kvazaar (I-frames), still honoring QP. The old preset settings field is retained for reading existing preferences. The underlying Kvazaar prediction defect is not repaired by this application change; software files are larger. Hardware is the normal export route.

Artifacts for this investigation are under target/verification:
problem-mp4-probe.json, problem-mp4-software.png, motion/ (previous inter-path oracle/movie/decode), and motion-safe/ (current GPU and all-intra oracle/movie/decode).
The user's original movie was not modified.
